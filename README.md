# C# Learning Path

This is my personal C# learning repository. I'm following a structured path from the absolute basics all the way to building web APIs with ASP.NET Core. Everything in here — the notes, the projects, the struggles — is mine.

---

## Why this exists

I wanted one place to keep my notes, track what I've learned, and have something to show for the hours I put in. Instead of scattering notes across random files and sticky notes, this repo is my living study journal.

---

## How it's organized

Each folder is a chapter. You read them in order.

- **00-Setup** — Getting the tools installed and the terminal working.
- **01-CSharp-Basics** — The fundamentals: variables, loops, methods, arrays.
- **02-OOP** — Object-Oriented Programming. Classes, inheritance, the whole thing.
- **03-Collections-and-LINQ** — Lists, Dictionaries, and querying data with LINQ.
- **04-Error-Handling-and-Debugging** — How to not let errors crash everything.
- **05-Async-and-Advanced-Concepts** — async/await, generics, delegates.
- **06-Working-with-Files-and-Data** — Reading/writing files, JSON serialization.
- **07-.NET-Concepts** — Dependency Injection, NuGet, configuration.
- **08-Web-Development-ASP.NET** — Building REST APIs with ASP.NET Core.
- **09-Real-World-Projects** — Complete projects that put it all together.

Each section has a `Notes/` folder with my personal notes and a `Projects/` folder with the code I wrote while practicing.
