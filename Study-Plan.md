# Study Plan — 2 Weeks

This is a focused, two-week plan to get through the fundamentals and write real C# code by the end of it. Not trying to learn everything — just enough to be productive and confident.

---

## Week 1 — Foundations

**Day 1–2: Setup and Orientation**
- Install .NET SDK and VS Code
- Get comfortable with the terminal and `dotnet` commands
- Understand [Solutions](./00-Setup/solutions.md) and [Project Structure](./00-Setup/namespaces-projects-assemblies.md)
- Explore Project Templates: [Console](./00-Setup/consoleapp.md), [Class Library](./00-Setup/classlib.md), [Web API](./00-Setup/webapi.md), [Unit Tests](./00-Setup/unittests.md)

**Day 3–4: C# Basics**
- Variables and data types
- Conditions (if/else, switch)
- Loops (for, while, foreach)

**Day 5–6: Methods and Arrays**
- Writing and calling methods
- Return values and parameters
- Arrays — creating, accessing, iterating

**Day 7: Mini Project**
- Build the Mini-Calculator in `01-CSharp-Basics/Projects/MiniCalculator/`
- It should handle add, subtract, multiply, divide, and invalid input

---

## Week 2 — Object-Oriented Programming

**Day 8–9: Classes and Objects**
- Creating classes with fields and properties
- Constructors
- Instantiating objects

**Day 10–11: The OOP Pillars**
- Encapsulation — private fields, public properties
- Inheritance — base and derived classes
- Polymorphism — virtual/override methods
- Abstract classes and interfaces

**Day 12–13: Collections and Basic LINQ**
- `List<T>` and `Dictionary<TKey, TValue>`
- Common List operations (Add, Remove, Contains)
- Basic LINQ: Where, Select, OrderBy

**Day 14: Capstone Project**
- Build the Banking System in `02-OOP/Projects/BankingSystem/`
- Apply classes, inheritance, and encapsulation to model real account types

---

## Daily approach

- Read the note for the day's topic first (15–20 min)
- Then write code. Don't just read — type it out and run it.
- At the end of each day, jot down one thing that was new or confusing. That's what the notes are for.

---

After these two weeks, I'll have covered enough to move on to error handling, async, and eventually web development.
