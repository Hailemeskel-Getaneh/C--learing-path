# Microsoft Learn — Useful Paths

These are the specific learning paths on Microsoft Learn that I'm following alongside this repo.

- [Get started with C#](https://learn.microsoft.com/en-us/training/paths/get-started-c-sharp-part-1/)
- [Add logic to your apps with C#](https://learn.microsoft.com/en-us/training/paths/csharp-logic/)
- [Work with variable data in C# console apps](https://learn.microsoft.com/en-us/training/paths/csharp-data/)
- [Object-Oriented Programming with C#](https://learn.microsoft.com/en-us/training/paths/csharp-object-oriented/)
- [Create methods in C#](https://learn.microsoft.com/en-us/training/paths/csharp-methods/)
- [Debug C# console apps](https://learn.microsoft.com/en-us/training/paths/csharp-debug/)
- [Handle errors in C# console apps](https://learn.microsoft.com/en-us/training/paths/csharp-exceptions/)

The best thing about Microsoft Learn is that you can run the code directly in the browser without needing anything installed. Useful for quickly testing concepts.
