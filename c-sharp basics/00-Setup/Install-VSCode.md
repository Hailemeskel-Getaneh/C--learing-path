# Setting Up: Visual Studio Code

VS Code is the editor I'm using for this path. It's lightweight, fast, and has great C# support through extensions.

## Installation

Download from [code.visualstudio.com](https://code.visualstudio.com/) and install it normally.

## Extensions to install

Once VS Code is open, install these three from the Extensions panel (Ctrl+Shift+X):

- **C# Dev Kit** — the main one. Gives you IntelliSense, error highlighting, and run/debug support.
- **IntelliCode for C# Dev Kit** — adds AI-assisted completions. Makes coding faster once you're used to it.
- **.NET Install Tool** — helps VS Code find the right SDK version.

## One thing that caught me out

After installing the C# Dev Kit, you might need to reload VS Code before it activates fully. If IntelliSense isn't working, try `Ctrl+Shift+P` and run "Reload Window".
